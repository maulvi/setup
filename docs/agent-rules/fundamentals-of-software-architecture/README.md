# Software Architecture Agent Rules

Distilled from **Fundamentals of Software Architecture** by Mark Richards and Neal Ford (2nd edition).

## Use

Keep `AGENTS.md` as the entry point and load the relevant topic file when the task requires deeper guidance.

These are concise operational rules, not a replacement for the book. They preserve its core framing: architecture is contextual, trade-offs are unavoidable, and the reason behind a decision matters more than the mechanism alone.

## Important limitation

This is a distilled rule set, not a chapter-by-chapter summary. Examples, case studies, discussion questions, and detailed style-specific comparisons have been intentionally omitted to keep agent context actionable. When a decision depends on a nuanced comparison or a specific technique, consult the cited chapter in the original book.

## Provenance

Rules are paraphrased and condensed; they are not verbatim extracts.
